Un peu d’aide
pour commencer.

Les premiers pas, simplement.

Fermez les autres applications qui utilisent votre webcam.

Sur Windows
  1. Faites un clic droit sur le ZIP, puis Extraire tout. Gardez tous les fichiers dans le même dossier.
  2. Ouvrez 4 - Lancer IA barre des taches.vbs et acceptez la confirmation Windows. Ce lanceur permet le suivi dans la barre des tâches, sans limite de durée.
  3. Choisissez votre caméra si demandé. Ajustez la vitesse et les clics dans les options.

Le lanceur « 1 - Demonstration sans camera.vbs » permet un essai sans webcam et sans commande du pointeur.

Cette version n’est pas signée numériquement. Si Windows affiche un avertissement, vérifiez la provenance du fichier et son empreinte SHA-256.

Guide Windows complet ↗
Sur macOS
  1. Ouvrez le ZIP et déplacez eViacam-YuNet.app dans Applications.
  2. Ouvrez l’application. Autorisez la Caméra et l’Accessibilité dans Réglages Système → Confidentialité et sécurité.
  3. Après l’autorisation Accessibilité, cliquez à nouveau sur Activer, puis ajustez le suivi.

Cette préversion n’est pas notariée par Apple. Si macOS la bloque, utilisez « Ouvrir quand même » dans Confidentialité et sécurité après vérification de la provenance. Ne désactivez pas Gatekeeper.

Guide macOS complet ↗

Les versions Mac ont passé les tests automatiques. La webcam, les autorisations et les clics réels restent à valider sur un Mac.

Le projet

Une variante communautaire d’Enable Viacam, créé par César Mauri, avec le détecteur de visage YuNet.

Tests et limites

Windows : compilation, tests hors caméra et essai utilisateur avec le correctif de la barre des tâches.

macOS : compilation Apple Silicon et Intel, tests du détecteur, du suivi et des événements souris, puis lancement sur une vidéo de 90 images. Le port cible l’écran principal et propose une barre de clics flottante, sans masquage automatique. Le démarrage automatique et le clavier visuel ne sont pas fournis.

Sur un petit jeu de tests, YuNet détecte correctement 82 cas sur 96, contre 36 pour Haar. Ces variantes synthétiques de trois portraits ne représentent pas toutes les webcams et tous les éclairages.
