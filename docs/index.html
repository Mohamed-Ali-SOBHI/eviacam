02 / Premiers pas

Téléchargez.
Installez. Ajustez.

Fermez toute autre application qui utilise la webcam avant de lancer eViacam.

Sur Windows

  1. Faites un clic droit sur le ZIP, puis choisissez Extraire tout. Conservez tous les fichiers dans le même dossier.
  2. Ouvrez 4 - Lancer IA barre des taches.vbs et acceptez la confirmation Windows. Ce lanceur active une session sans limite de durée.
  3. Choisissez la caméra si demandé, puis ajustez la vitesse et le clic dans les options. Le lanceur 1 - Demonstration sans camera.vbs permet de découvrir le suivi sans webcam.

Version communautaire non signée. Windows peut afficher un avertissement : vérifiez la provenance du fichier et son empreinte avant l’exécution.

Lire le guide Windows ↗

Sur macOS

  1. Ouvrez le ZIP et déplacez eViacam-YuNet.app dans le dossier Applications.
  2. Ouvrez l’application et autorisez la Caméra, puis l’Accessibilité dans Réglages Système → Confidentialité et sécurité.
  3. Après l’autorisation Accessibilité, cliquez à nouveau sur Activer. Ajustez ensuite le suivi et le clic.

Préversion non notariée par Apple. Si macOS la bloque, utilisez « Ouvrir quand même » dans Confidentialité et sécurité après vérification du téléchargement. Ne désactivez pas Gatekeeper.

03 / Un projet ouvert

Local, libre.
Et encore perfectible.

Cette variante communautaire s’appuie sur Enable Viacam de César Mauri et ajoute le détecteur de visage YuNet. L’analyse des images reste sur votre ordinateur.

Explorer le code source ↗
Qu’est-ce qui a été testé ?

Windows : compilation, tests hors caméra et essai utilisateur avec le correctif de la barre des tâches.

macOS : compilation Apple Silicon et Intel, tests du détecteur, du suivi et des événements souris, puis lancement de l’application sur une vidéo de 90 images. La webcam, les autorisations et les clics réels restent à valider sur un Mac.

Voir les tests macOS ↗
YuNet détecte-t-il mieux les visages ?

Sur notre petit jeu de tests hors caméra, YuNet détecte correctement 82 cas sur 96, contre 36 pour Haar. Ce sont des variantes synthétiques de trois portraits : ces résultats ne garantissent pas les mêmes performances avec toutes les webcams et tous les éclairages.

Quelles sont les limites de la version Mac ?

macOS 15 minimum, écran principal uniquement, barre de clics flottante sans masquage automatique. Le démarrage automatique et le clavier visuel ne sont pas fournis dans ce premier port.

Où trouver les anciennes versions ?

L’ancienne version Windows 2.1.4.1 et son installateur restent disponibles. Elle précède la version YuNet proposée ici.
